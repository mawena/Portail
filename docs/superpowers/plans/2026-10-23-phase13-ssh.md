# Portail — Phase 13 : connexions SSH (terminal, clés, tunnels) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** Portail devient un client SSH complet : terminal compatible xterm sur les serveurs SFTP enregistrés, sessions
multiples qui restent ouvertes en arrière-plan, connexions aux messages d'échec précis (et `mawena.cloud:2244`
corrigé), trousseau de clés avec génération et installation sur le serveur, commandes enregistrées et tunnels. Fin de
phase : version **v1.6.0**.

**Architecture :**
- **Kotlin, paquet `com.mawena.fluluks.remote.ssh`** : `SshConnector` ouvre une `Session` JSch (empreinte, clé ou mot
  de passe, keyboard-interactive, journal de tentative, erreurs traduites) pour **tous** les usages SSH : `SftpClient`
  (phase 10) l'utilise désormais, comme le terminal, les tunnels et l'installation de clé. `TerminalSessions` garde les
  sessions interactives (`ChannelShell`, PTY `xterm-256color`), leur sortie récente en mémoire, et parle à Dart par
  Pigeon. `SshService` (service au premier plan) les garde en vie hors de l'écran.
- **Flutter** : `xterm` 4.0.0 affiche le terminal (`Terminal` + `TerminalView`) ; Dart ne fait qu'envoyer les octets
  tapés et afficher ceux reçus. Un `TerminalHub` (dans `AppState`) tient les sessions côté Dart, pour que l'écran se
  ferme et se rouvre sans rien perdre.
- **Rien de nouveau sur le disque en clair** : clés scellées par `SecretBox` (Keystore) comme en phase 10 ; commandes
  et tunnels (non secrets) en JSON ; sortie des terminaux en mémoire seulement.

**Tech Stack :** Kotlin, JSch 2.28.8 (mwiede) et Bouncy Castle 1.86 (déjà présents), Pigeon 27.3.0, Flutter 3.41,
**xterm 4.0.0** (Dart, MIT, seule nouvelle dépendance d'exécution), JUnit 4 avec Apache MINA SSHD 2.20.0 (déjà en
`testImplementation`), AndroidX Test.

**Spec :** [docs/superpowers/specs/2026-10-17-fluluks-design.md](../specs/2026-10-17-fluluks-design.md), **§ 21** (et
§ 18 pour les dossiers distants de la phase 10).

## Review Focus

1. **Secret qui fuit** : mot de passe, phrase de clé ou code keyboard-interactive dans le journal de tentative, un
   message d'erreur, un `String` Kotlin gardé, ou la sortie récente. → T1 : `connectionLogNeverContainsSecrets`,
   `promptAnswersZeroed` ; T2 : `passwordNeverInBacklog`.
2. **Empreinte contournée** par un nouveau chemin (terminal, tunnel, installation de clé, Tester la connexion) : clé
   inconnue demandée, clé changée refusée, comme en phase 10. → T1 : `testConnectionAsksForUnknownKey` ; T2 :
   `terminalRefusesChangedHostKey` ; T8 : `installRefusesChangedHostKey` ; T10 : `tunnelRefusesChangedHostKey`.
3. **Session perdue** (réseau changé, serveur redémarré, téléphone en veille) : la session passe à « Fermée » avec un
   message et « Reconnecter », rien ne reste figé, le service s'arrête avec la dernière session. → T2 :
   `serverDropClosesSession` ; T3 : `serviceStopsWithLastSession`, `closeAllFromNotification`.
4. **Sortie massive** (`cat` d'un gros fichier, `yes`) : l'interface reste fluide, la mémoire bornée, et Ctrl+C passe.
   → T2 : `floodIsBatchedAndBounded` ; T4 : `ctrlCReachesDuringFlood`.
5. **`authorized_keys` abîmé** par l'installation : lignes existantes perdues, doublon, droits trop ouverts, lien
   symbolique suivi. → T8 : `installKeepsExistingKeys`, `installIsIdempotent`, `installSetsModes`,
   `installRefusesSymlinkedFile`.

## Décisions du planificateur

Prises en l'absence de l'utilisateur, puis **toutes validées par l'utilisateur le 2026-10-23** ; chacune se change
à faible coût si l'essai la contredit.

1. **Terminal affiché par `xterm` (Dart), SSH en Kotlin** : JSch est déjà là, vérifié avec les empreintes et le
   Keystore ; `xterm` 4.0.0 est un émulateur complet (256 couleurs, mode curseur d'application, souris, OSC) en Dart
   pur, sans code natif. *Coût si faux : la vue du terminal de Termux (Apache-2.0) en vue Android, la partie Kotlin
   restant la même.*
2. **Une session JSch par terminal**, distincte de celle de l'explorateur SFTP : une sortie massive ou une coupure ne
   gèle pas l'autre. *Coût si faux : une authentification de plus par terminal ; partager la session est un
   changement local à `TerminalSessions`.*
3. **Sessions gardées par un service au premier plan** (type `specialUse`, notification « Tout fermer ») plutôt
   que fermées en quittant l'écran : c'est l'usage des clients SSH mobiles (Termius, JuiceSSH). *Coût si faux :
   fermer les sessions à la sortie de l'application, le service disparaît.*
4. **Sortie récente de 256 Kio par session en Kotlin** pour retrouver l'écran après la destruction de l'activité ;
   jamais sur le disque. *Coût si faux : une constante.*
5. **Le terminal réutilise les serveurs SFTP** (pas de type « SSH » à part) : mêmes adresse, utilisateur, empreinte et
   clé. *Coût si faux : un protocole `ssh` sans explorateur, un choix de plus dans le formulaire.*
6. **Trousseau de clés commun** au lieu d'une clé par serveur, avec migration des clés de la phase 10 ; Ed25519 par
   défaut. *Coût si faux : garder aussi l'import par serveur, qui resterait un raccourci vers le trousseau.*
7. **Installation de la clé publique par SFTP** (comme `ssh-copy-id`, sans lancer de commande sur le serveur), refusée
   sur un lien symbolique. *Coût si faux : une commande `sh` distante.*
8. **Tunnels locaux seulement** (`-L`), liés à `127.0.0.1` ; pas de redirection distante (`-R`) ni dynamique (`-D`,
   SOCKS), pas d'agent SSH, pas de saut par un hôte intermédiaire : à demander pour une phase suivante.
9. **Collage de plusieurs lignes confirmé** (il exécuterait des commandes) ; une ligne se colle directement.
10. **Masquage du terminal dans les captures désactivé par défaut** (l'utilisateur fait des captures), réglage dans
    Confort.
11. **Ce qui est mémorisé** : la taille du texte (13 par défaut) et les tunnels « auto » sont mémorisés ; la
    sortie, l'historique des commandes tapées et les sélections ne le sont jamais.
